# Bazar Carmita

Primera versión de una landing page estática para una boutique de belleza inspirada en Cristiano Ronaldo, desarrollada con HTML semántico, CSS moderno y JavaScript vanilla.

## Incluye

- Header, nav, main y footer semánticos.
- Barra de ofertas promocionales.
- Menú de categorías.
- Grid de productos con precios en dólares.
- Imágenes reales con alt descriptivos.
- Botones de añadir al carrito con contador.
- Diseño responsive y foco visible.

## Ejecutar localmente

Desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000/
```
